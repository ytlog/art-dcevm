# Original source cleanup owner

`native_required_cleanup::{Binding,Service,Facade}` composes the existing concrete native services for one original ART Run. It does not authorize a stop by callback installation or by symbol presence. `Binding` is a readonly prerequisite: original public `GetJavaVM`, named actual `CurrentFromGdb`, calibrated fields/cache, the exact runtime/VM/ThreadList/JIT receivers, and the actual source/reflection function bindings must agree. Missing JIT observation is refused.

Construct Service in BeginRun, before a Holder exists. `AttachHolder` later accepts one actual Holder and its independently captured Metadata: the mapped fixed header, root-handle slot, complete native owner allocation and bit-vector ranges, source-declaration stride, exact snapshots, actual driver/self and every owner's driver must agree. Stop-time reads also compare the live header, owner range and every driver. No second attachment is accepted.

Before Session.Begin, register all managed identities using ordinary JNI, then freeze/resolve the concrete Registry and allocate scanner storage. Under actual Collected stop, `PrepareCollected` binds the canonical Plan through `Registry.Existing()` and physically walks all registered threads. The native provider may then build its actual services and bind their managed slots only through Existing. `Prepare` accepts the concrete provider-owned native delegate; a foreign source, provider, reflection owner or receiver is refused. All this remains refundable. The facade is allocated here.

After continuous transfer into the original final native scope, refresh the canonical Plan and native provider from the already resolved Registry, then call `RefreshFinal`. No registration, JNI, decoding or vector construction occurs in this refresh. Facade.Validate repeats the complete physical walk and the original native/reflection validation in the actual final scope. The sole source Run's existing observer must call `CommitObserver(plan)` and then hierarchy Ledger.BeginCommit; the facade's BeginCommit consumes that exact validated observer/ledger prefix. No second Run or second hierarchy BeginCommit is permitted through the reflection publication callback.

The facade forwards the original status/copy/obsolete/reflection/deopt/heap-replacement/declaring-root/old-class-retention/JIT-invalidation/cache-cleanup sequence. Pair indices and stage counts follow real delegate returns. Completion is recorded only after the original native interpreter-cache clearing returns. Source-native storage remains borrowed from the exact live Run; strong globals belong to the existing Registry and are released only outside the stop. Facade destruction clears the provider's prepared-source identity; it does not perform another native cleanup.

The reflective closure remains the original `Runtime::VisitReflectiveTargets`, including ThreadList, Heap, JniIdManager and every RuntimeCallbacks consumer. This module does not replace callbacks with empty visitors or infer their safety from names. It relies on the same original source-exclusive/no-GC scope proven by Session, the existing concrete visitor's independently calibrated member/handle guards, and the production source ownership proof. Third-party callbacks are not separately granted permission by this facade. Production enablement still requires successful real source lifecycle and full-frame calibration.

Fixed source references:

- [Android 13 Runtime visitor](https://android.googlesource.com/platform/art/+/refs/tags/android-13.0.0_r1/runtime/runtime.cc#2501): ThreadList, Heap, JNI ID manager, RuntimeCallbacks closure. Their component visitors retain their original source locking and visit behavior.
- [Android 13 runtime callbacks](https://android.googlesource.com/platform/art/+/refs/tags/android-13.0.0_r1/runtime/runtime_callbacks.cc#325): every registered reflective callback is retained.
- [Android 12 JavaVMExt](https://android.googlesource.com/platform/art/+/refs/tags/android-12.0.0_r1/runtime/jni/java_vm_ext.cc#663): AddGlobalRef calls allocation tracking after adding the root. Tracking can enter Native suspension, so registration is prohibited inside the stop.
- [Android 12 indirect-reference table](https://android.googlesource.com/platform/art/+/refs/tags/android-12.0.0_r1/runtime/indirect_reference_table.cc): Add/Resize can grow native mapped storage; immutable Existing lookup supplies no substitute registration permission.

`whole_process_frames.cc` holds a single strongly defined typed enumeration thunk. It forwards the same thread/state arguments to the unchanged complete scanner. This also avoids a Mach-O weak-inline sanitizer metadata prefix being coalesced into a preceding weak atom when the scanner is used across actual TUs. Function sanitizer stays enabled; the host test independently rejects a deliberately wrong callback signature.
